## 2024-05-19 - Optimize DOM Attribute Sanitization Path
**Learning:** In JavaScript hot paths like `sanitize.js`, using an inline array instantiation combined with `.includes()` for membership checks (e.g., `['style', 'src', 'srcset', ...].includes(attrName)`) causes a new array allocation and an O(N) iteration on *every* attribute of *every* DOM element processed.
**Action:** Replace inline array `.includes()` lookups in high-frequency loops with direct string equality checks (`attrName === 'a' || attrName === 'b' ...`) or module-level `Set.has()`. Direct checks are significantly faster (up to ~6x in V8) and eliminate unnecessary garbage collection pressure.
