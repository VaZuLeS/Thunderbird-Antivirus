- [English – Installation, configuration, testing and operation](../../docs/python-receiver.en.md)

Die ZIP-Datei für den eigenständigen Betrieb steht unter [GitHub Releases](https://github.com/VaZuLeS/Thunderbird-Antivirus/releases/latest) als `thundy-python-receiver-<Version>.zip` bereit.

For source development, run `python -m unittest discover -v -s examples/python-receiver` from the repository root after installing `requirements.txt`. The tests also use Node.js and OpenSSL.
