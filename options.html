What is Hybrid Analysis?

Hybrid Analysis is a malware analysis service. You can submit files for static and dynamic analysis.

Hybrid Analysis uses CrowdStrike Falcon Sandbox to investigate unknown threats.

Provider accounts and service terms apply to external analysis. Local checks do not require an account.
