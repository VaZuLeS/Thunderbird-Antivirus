# Thundy AV 1.20.0 — Link decisions and administrator review

Link protection now records intercepted HTTP(S) clicks with full URL, timestamps, local message/link risk score, provider verdict and the user's decision. Successful browser handoffs are recorded as opened; cancelled interactions and opening errors remain distinct. Later check results preserve the decision-time snapshot.

- Open **Review link log** from settings or the message popup. Filter by URL/domain, decision, minimum local score and date range. The overview highlights links opened at high risk using the assessment available at the decision time.
- JSON and spreadsheet-safe CSV exports include all filtered records, not just the visible page. JSON includes a SHA-256 checksum; `scripts/verify-link-audit-export.js` verifies it.
- Unknown numeric scores are represented by `null`; provider verdicts remain separate from local 0–100 heuristic scores. Opening retries update the same interaction and count attempts.
- Audit writes are serialized and retained independently of scan caches for up to 30 days, 2,000 events and 2 MiB. There is a separate confirmed deletion action.
- Full English, German, French, Spanish, Italian and Polish interfaces are bundled.

This is a local review/export feature. It does not automatically upload records, establish employee identity, prove website visits or record native context-menu browser openings. Profile users can alter/delete the local log; the unkeyed export checksum does not authenticate evidence. Full URLs and assessment reasons may contain personal data or tokens. Storage failures are reported and do not guarantee that a browser handoff was logged.

Validation: 517 automated tests, no lint errors, a verified runtime package and 48 browser layout cases (18 administrator views plus 30 popup/link-dialog cases). The browser checks use mocked data. The XPI remains unsigned, and real Thunderbird acceptance remains pending.
