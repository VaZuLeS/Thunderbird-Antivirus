# Thundy AV 1.19.0

Thundy AV now bundles complete English, German, French, Spanish, Italian and Polish interfaces, including error messages, accessibility labels and local privacy information. Local checks work without provider API credentials.

- Automatic external scans require both global consent and a message/sender authorization. Full URLs are restricted to the Maximum privacy tier, including urlscan.io.
- Saving settings keeps transmission disabled while the combined data/host permission request is pending or denied. Withdrawing consent cancels running and queued requests.
- Link clicks pause for an explicit result and opening decision, including keyboard and middle-click handling.
- Local HTML sanitization is available without external analysis; text/HTML attachments and MIME part arrays are processed correctly.
- Reputation caches expire; provider errors remain unknown instead of being cached as clean. Provider/attachment concurrency, retries, deadlines and persistent-cache retention are bounded.
- Domain checks use a bundled Public Suffix List. Authentication reports require explicitly trusted recipient servers.
- CI validates all tests, bundled translation/vendor data, lint and the packaged XPI. GitHub Pages now provides six language landing pages.

Validation: **485 passing tests**, **0 lint errors**, and a verified package with all six language catalogs. The release workflow rebuilds and verifies the tagged source and publishes `SHA256SUMS.txt` alongside the XPI.

**The XPI is unsigned. Thunderbird 140 ESR/current-client live testing and genuine client screenshots remain outstanding.** This GitHub release is not a signed Thunderbird Add-ons Store submission. The manual protocol is available in `docs/live_test_1_19_0.md`.

Version 1.19.0 uses a fresh tag above the existing v1.7.0–v1.18.0 prerelease tags. Existing releases and tags are preserved.
