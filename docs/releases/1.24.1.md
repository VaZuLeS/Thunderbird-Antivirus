# Thundy AV 1.24.1 — Provider connection audit

- Connection audit across all five analysis services (Hybrid Analysis, VirusTotal, urlscan.io, URLhaus, AbuseIPDB): endpoints, methods and authentication headers match the provider APIs; no functional defects found. Gateway-injected and adapter-level auth headers are consistent.
- Removed the `user-agent: Falcon` request header — a forbidden header name for `fetch`, so it was never actually sent — and a redundant `scan_type` header already carried by the form body.
- `https://www.virustotal.com/*` is now declared explicitly in `optional_host_permissions` (previously covered only via the `*.virustotal.com` wildcard), making the VirusTotal permission grant deterministic.
- No changes to the consent model, privacy tiers, requested data or scan behavior.
