# Thundy AV 1.22.0 — First-install setup / Einrichtung nach Installation

- A three-step setup wizard opens on first installation, with complete English, German, French, Spanish, Italian and Polish text.
- Configure link protection and review the local audit limits. Optional external analysis leads to settings, where consent and provider permissions are separately requested.
- Updates do not reopen setup. Existing settings, keys, consent, sender approvals and logs are preserved. Reopen setup from settings or postpone without saving.
- New release uses **GNU GPL v3 only (`GPL-3.0-only`)** and includes the full license text. Third-party notices remain unchanged.
