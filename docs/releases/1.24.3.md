# Thundy AV 1.24.3

Unsigned GitHub distribution for Thunderbird 140+. This release is not ATN-signed and does not establish an ATN listing or automatic update channel. Install the XPI manually through Thunderbird’s add-on manager and compare it with SHA256SUMS.txt. A checksum is not an independent publisher signature.

- Restores Hybrid Analysis report persistence, bounded polling and provider authentication missing from main; prevents obsolete popup responses from replacing newer submissions.
- Parses authentication-result tokens structurally and separates current provider observations, stored results and failed check attempts. Authentication headers remain local heuristics, not cryptographic SPF/DKIM verification.
- Preserves decision-time scores, verdicts and reasons separately from later findings. OPENED means Thunderbird accepted the opening request; browser startup or a website visit is not confirmed. PENDING remains incomplete after process loss.
- Shows scan coverage and existing limits without increasing upload amounts. Unchanged audit reads avoid redundant writes.
- Adds a previewed local minimal support export and versioned appearance-profile import/export. Profiles transfer only appearance, accent and density after confirmation; keys, consent, permissions, protection rules and history are excluded.
- Includes English, German, French, Spanish, Italian and Polish, shared themes/density/keyboard controls, corrected Vite/PSL dependencies, stronger report validation and reduced duplicate CI work. Enterprise profiles and Node tools remain optional and separate from productive integrations; the React app remains a separate simulation.

Validation covers source/build checks, Node 22/24 tests, 600 Chromium/axe cases and 36 CSS-zoom cases, plus real Linux Thunderbird 140/153 ESR upgrades, restart/SIGKILL recovery, clean profile restore, native MIME/coverage, support downloads and appearance-profile round trips. See the [release scope and evidence](../VEROEFFENTLICHUNG_1_24_3.md). Browser API doubles are not real OS or screenreader acceptance.

Known limits: real Windows/macOS, NVDA/VoiceOver, native DPI/high contrast, automatic update distribution, ATN, live provider contracts and productive enterprise acceptance still require external resources. The development-tool dependency audit retains nine moderate and one low finding, with no high/critical finding in the candidate npm tree; no unsupported downgrade or unverified override is used. Externally transmitted data cannot be recalled by local consent withdrawal.
