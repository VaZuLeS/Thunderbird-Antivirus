# Thundy AV 1.19.1

Fixes two regressions reported in 1.19.0: the message-action popup collapsing into a narrow strip, and the intercepted-link dialog failing to open confirmed links.

- The popup has a stable 600 px width independent of its initial viewport. Local risk, message metadata, consent and stored analysis results have distinct sections; technical IDs are collapsed by default.
- Confirmed HTTP(S) links open in the system default browser via Thunderbird’s documented `windows.openDefaultBrowser` API. The background validates the current message before opening. Failure leaves the dialog visible and enables retry.
- The redesigned Thundy AV link dialog shows the destination domain, expandable full URL, warning or uncertainty, and available reasons. It supports dark mode, narrow panes, keyboard focus and Escape. Shadow DOM isolates it from email styling.
- Cancel, pending checks, changed destinations and changed messages cannot silently open a link. Native right-click context menus remain available.
- Consent information remains visible after results load. An empty result cache is described as missing stored results, rather than claiming the message contains no links or attachments.
- All new text is bundled in English, German, French, Spanish, Italian and Polish.

Validation: 493 automated tests passed, 0 lint errors (23 documented Thunderbird-specific false positives), package checks passed. Browser rendering checks cover all six languages, light/dark popup views, narrow and wide dialogs, 200% zoom, and hostile email CSS. These browser previews use mocked message data and are not Thunderbird client screenshots.

The XPI is unsigned. Live verification in Thunderbird 140 ESR/current Thunderbird remains outstanding; see the [manual checklist](https://vazules.github.io/Thunderbird-Antivirus/live_test_1_19_1.html). This release does not change external-analysis consent or privacy tiers.
