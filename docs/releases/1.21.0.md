# Thundy AV 1.21.0 — Optional enterprise profiles

Settings now offer a complete six-language offline assistant for optional hosting, SSO, device-management, SIEM and ticket profiles. Suggested combinations can be edited independently and external systems can be disabled.

- Hosting: local preparation, self-hosted, Azure, AWS and Google Cloud.
- SSO: Entra ID, Keycloak, Okta and generic OIDC.
- Devices: Intune, Jamf, Ansible and generic package/MDM distribution.
- SIEM: Sentinel/Logs Ingestion, Splunk HEC, Elastic and HTTPS JSON.
- Tickets: Jira Cloud/Data Center, ServiceNow and GitLab Issues.
- Save profile identifiers locally, export a disabled JSON draft, or generate one with the matching Node CLI. CLI output files are private on POSIX and existing files are never overwritten.

These are configuration preparation profiles. No backend, broker, login, adapter or cloud deployment is activated or implemented by selecting them. Exports contain required setting names and secret reference names, no secret values or user activity. Existing scan consent and local link logging remain unchanged. Full enterprise implementation and real Thunderbird/OS acceptance remain pending.

Validation: 552 automated tests, zero lint errors, verified runtime package and 24 six-language light/dark Chromium profile layouts using mocked Thunderbird APIs. The XPI remains unsigned.
