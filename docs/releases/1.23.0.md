# Thundy AV 1.23.0 — Fresh settings and shared themes

- Redesigned settings with six clear sections, responsive navigation, grouped provider fields and a persistent Save action.
- Follow Thunderbird appearance, or choose Light or Dark; select Ocean, Violet, Forest or Amber accents.
- Appearance saves independently and updates open add-on pages. Wizard, scanner, local tools and message security UI share the theme.
- Full English, German, French, Spanish, Italian and Polish text. Keyboard focus, reduced motion, system contrast support and retryable saving.
- New `theme` permission reads native colors and theme updates; no changes to Thunderbird's theme, scan consent or provider permissions.

Modernisierte Einstellungen mit gemeinsamer Theme-Auswahl. Die Darstellung wird sofort lokal gespeichert; andere Einstellungen weiterhin über „Speichern“. Native Thunderbird-Farben werden geprüft, Warnfarben behalten ihre Bedeutung.
