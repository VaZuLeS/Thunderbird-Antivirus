# Thundy AV 1.25.1

Opening a message now starts Hybrid Analysis and urlscan.io independently when the selected scan mode, external consent, provider permissions and privacy tier allow it. Full URL submissions require Maximum; automatic URL submissions also require automatic link analysis. urlscan.io submissions remain unlisted, not private.

A shared background job provides visible Check now, progress, Refresh results and Check again actions in both the message and popup. Closing the popup no longer stops provider result processing. Duplicate display events share a job; automatic reopening reuses completed results for 15 minutes. Explicit retries bypass that freshness cache. Pending provider identifiers are saved for result refresh without duplicate submission.

Existing profiles retain sender approvals and manual mode until a scan mode is explicitly chosen. The new All opened messages mode expands the transmission scope only after selection and saving in settings. Administrator protection and link approval rules remain enforced. Scan state and actions are translated into all six languages.

Distribution remains an unsigned GitHub XPI. Publication is controlled by the existing package-bound Linux Thunderbird, browser and regression release gate. Windows/macOS and screen-reader acceptance remain separate.
