About the project

Thundy AV is an open-source Thunderbird add-on (MIT license). It analyses the message you open inside Thunderbird: headers, message text, links and attachments. Scoring and heuristics run locally. If — and only if — you enable external analysis and trigger a scan, the add-on can query analysis services such as Hybrid Analysis, VirusTotal, urlscan.io, URLhaus (abuse.ch) and AbuseIPDB.

Setup & API key

External analysis requires your own free API key. Each user works with their own account (fair use).

Step 1: Register for free at hybrid-analysis.com.
Step 2: After logging in, open your profile menu (top right) → "Profile" and copy the API key from the API settings.
Step 3: In Thunderbird, open the add-on's options dialog and paste the key.
Step 4: Enable the checkbox "Allow external analysis" (default: off) and choose a privacy tier: strict sends only SHA-256 hashes, balanced additionally uploads unknown files, max additionally submits URLs from the message. When you save a key, Thunderbird asks for the optional host permission for that provider.

Privacy & security

  • The add-on reads the message you open in Thunderbird — headers, text, links and attachments. This happens locally on your computer and is not transmitted.
  • Nothing is transmitted to third parties until you enable "Allow external analysis" and trigger a scan (per message or with a permanent opt-in for that sender). While the consent is off, there is no upload, no hash lookup, no URL/domain lookup and no IP lookup.
  • Depending on the privacy tier and the keys you configure, SHA-256 hashes of attachments (Hybrid Analysis, VirusTotal), complete attachments of unknown files (Hybrid Analysis, tier balanced/max), URLs from the message (Hybrid Analysis in tier max, urlscan.io) and domains (URLhaus) may be transmitted; IP addresses from Received headers are only checked if you configure a provider for that.
  • The message body, the subject line and the sender/recipient addresses are not transmitted as such. Only the individual links contained in the message can be submitted (see above), and never before you gave your consent. There is no telemetry, no analytics and no server operated by the developer; the developer has no access to your data.
  • Settings, consent flags and API keys are stored locally in Thunderbird (browser.storage.local, unencrypted). Scan results live in a local IndexedDB database that you can empty with "Clear cache" in the options.
  • Host permissions for the analysis providers are optional and are requested only when you save a key for that provider.

Project status

Thundy AV is not yet listed in the Thunderbird Add-ons Store, so there is no store download link. The current XPI and the sources are available in the GitHub releases. Screenshots are not available yet (only placeholder graphics) and the manual verification in Thunderbird 140 ESR is still outstanding.
