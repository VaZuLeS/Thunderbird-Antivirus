Local checks work without an account or API key.

Thundy AV reads the displayed message, its sender, subject, headers, text and attachments to perform local checks. Local checks work without API keys. There is no telemetry and no developer analysis server.

Local checks work without API keys. External scans require your consent and a message or sender authorization.

Privacy and data

Without consent, nothing is sent externally. After consent, only explicitly authorized messages or senders are scanned. Hashes, domains and public IPs may be sent in Strict; Balanced also permits unknown file uploads; Maximum also permits complete URL uploads. Turn this option off to stop new transfers and cancel pending requests. Previously transmitted data cannot be recalled.

Authorized external requests go directly to configured providers: Hybrid Analysis for file hashes and uploads, VirusTotal for file hashes or IP reputation, URLhaus for domains, urlscan.io for complete URLs and AbuseIPDB for public IPs. Hashes can identify known files. Provider terms and privacy policies apply; submitted data may be shared by the provider.

urlscan.io submissions are unlisted, not private. A complete URL can contain personal data or access tokens. Submit only URLs you are allowed to share.

Settings, consent, sender authorizations and API keys are stored in your Thunderbird profile. API keys are not encrypted there. Local scan records can include subjects, sender addresses, complete links and attachment metadata. The cache retains up to 1,000 message records for 30 days and is cleaned on database startup. In-memory reputation results expire after 15 minutes.

Turn off external analysis to stop new requests and cancel pending requests. Already transmitted data cannot be recalled. Use Clear cache to delete stored analysis results and reputation caches. Individual sender authorizations can be removed in settings.
