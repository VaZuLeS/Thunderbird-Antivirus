Las comprobaciones locales funcionan sin cuenta ni clave API.

Thundy AV lee el mensaje abierto, su remitente, asunto, cabeceras, texto y adjuntos para realizar comprobaciones locales. Funcionan sin claves API. No hay telemetría ni servidor de análisis del desarrollador.

Las comprobaciones locales funcionan sin claves API. Los análisis externos requieren consentimiento y autorización para un mensaje o remitente.

Privacidad y datos

Sin consentimiento no se envía nada. Después, solo se permiten análisis autorizados por mensaje o remitente. Estricto permite hashes, dominios e IP públicas; Equilibrado añade archivos desconocidos; Máximo añade URL completas. Desactiva esta opción para detener nuevos envíos y cancelar solicitudes pendientes. Los datos ya enviados no pueden recuperarse.

Las solicitudes autorizadas van directamente a los proveedores configurados: Hybrid Analysis para hashes y archivos, VirusTotal para hashes o reputación de IP, URLhaus para dominios, urlscan.io para URL completas y AbuseIPDB para IP públicas. Los hashes pueden identificar archivos conocidos. Se aplican las condiciones y políticas de los proveedores; pueden compartir los datos recibidos.

Los envíos a urlscan.io no están listados, pero no son privados. Una URL completa puede contener datos personales o tokens de acceso. Envía solo URL que puedas compartir.

Los ajustes, el consentimiento, las autorizaciones de remitentes y las claves API se guardan en tu perfil de Thunderbird. Las claves no están cifradas. Los resultados locales pueden incluir asuntos, remitentes, enlaces completos y metadatos de adjuntos. La caché conserva hasta 1000 mensajes durante 30 días y se limpia al iniciar la base de datos. La reputación en memoria caduca tras 15 minutos.

Desactiva el análisis externo para detener nuevas solicitudes y cancelar las pendientes. Los datos enviados no pueden recuperarse. Vaciar caché elimina los resultados locales y las cachés de reputación. Puedes eliminar autorizaciones de remitentes individualmente en los ajustes.

Política detallada (inglés/alemán)

Registro de decisiones sobre enlaces

Registra los clics HTTP(S) interceptados por la protección de enlaces. Abierto significa entrega al navegador predeterminado, no confirmación de visita. Las aperturas desde el menú contextual nativo no se registran.

Almacenamiento local: hasta 30 días, 2000 entradas o 2 MiB; se eliminan las más antiguas. Las URL completas pueden incluir datos personales o tokens. Sin carga automática. Los usuarios del perfil pueden modificar o borrar el registro; no es una auditoría central inalterable. La puntuación local usa el enlace y el contexto del mensaje, no una puntuación del proveedor. Los motivos de la evaluación pueden incluir datos del remitente o del dominio.
