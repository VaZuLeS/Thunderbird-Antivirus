Les vérifications locales fonctionnent sans compte ni clé API.

Thundy AV lit le message affiché, l’expéditeur, l’objet, les en-têtes, le texte et les pièces jointes pour des vérifications locales. Elles fonctionnent sans clé API. Il n’y a ni télémétrie ni serveur d’analyse du développeur.

Les vérifications locales fonctionnent sans clé API. Les analyses externes exigent votre consentement et l’autorisation pour un message ou un expéditeur.

Confidentialité et données

Sans consentement, aucune donnée n’est transmise. Après consentement, seules les analyses autorisées par message ou expéditeur sont permises. Strict autorise les hachages, domaines et IP publiques ; Équilibré ajoute les fichiers inconnus ; Maximal ajoute les URL complètes. Désactivez cette option pour arrêter les nouveaux transferts et annuler les requêtes en attente. Les données déjà transmises ne peuvent pas être rappelées.

Les requêtes autorisées vont directement aux services configurés : Hybrid Analysis pour les hachages et fichiers, VirusTotal pour les hachages ou la réputation IP, URLhaus pour les domaines, urlscan.io pour les URL complètes et AbuseIPDB pour les IP publiques. Les hachages peuvent identifier des fichiers connus. Les conditions et politiques des services s’appliquent ; ils peuvent partager les données reçues.

Les envois à urlscan.io sont non répertoriés, mais pas privés. Une URL complète peut contenir des données personnelles ou des jetons d’accès. N’envoyez que des URL que vous avez le droit de partager.

Les paramètres, consentements, autorisations d’expéditeur et clés API sont enregistrés dans votre profil Thunderbird. Les clés ne sont pas chiffrées. Les résultats locaux peuvent contenir objets, adresses d’expéditeur, liens complets et métadonnées de pièces jointes. Le cache conserve au plus 1 000 messages pendant 30 jours et est nettoyé au démarrage de la base. La réputation en mémoire expire après 15 minutes.

Désactivez l’analyse externe pour arrêter les nouvelles requêtes et annuler les requêtes en attente. Les données déjà transmises ne peuvent pas être rappelées. Vider le cache supprime les résultats locaux et les caches de réputation. Les autorisations d’expéditeur peuvent être supprimées individuellement dans les paramètres.
