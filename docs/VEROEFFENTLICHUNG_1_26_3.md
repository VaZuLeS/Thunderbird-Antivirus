# Veröffentlichung 1.26.3

Thundy AV 1.26.3 ist als unsigniertes XPI auf GitHub verfügbar. Der eigenständige Python-Empfänger liegt als ZIP mit Konfigurationsbeispiel und Anleitungen auf Deutsch und Englisch bei. [GitHub-Release](https://github.com/VaZuLeS/Thunderbird-Antivirus/releases/tag/v1.26.3)

Der unabhängige Downloadabgleich bestätigte die SHA-256-Werte aller vier Dateien, den Tag-Commit und die Paketversion. Das XPI enthält 24 EU-Sprachkataloge. Die XPI-SHA-256 lautet `57ecec4d21789c5459022dc751b5e9249953d2bbe645dba1182628b69b796f55`. [Maschinenlesbarer Nachweis](audits/release-1.26.3.json)

Die Release-CI prüfte das Upgrade von 1.26.2 in zwölf Installations-, Upgrade- und Profilwiederherstellungsfällen unter Linux mit Thunderbird 140.12.0 ESR und 153.7.0. Die Browserprüfung deckte sechs Sprachen ab. Offen bleibt der Test mit einem nativen Windows-Kontrastdesign und einem Screenreader.
